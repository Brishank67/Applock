How to install

  1. Tap Download APK above and open the downloaded file.
  2. If your phone asks, allow installs from your browser (Settings → Install unknown apps).
  3. If Google Play Protect shows a warning for a new app, tap More details, then Install anyway.
  4. Open AruShield, create your PIN and security question, and allow the permissions it asks for.
  5. Pick the apps you want to lock.
AruShield needs Usage access (to know which app is open), Display over other apps (to show the lock screen) and, only if you turn on Uninstall Protection, Device administrator. Details are in the privacy policy.
